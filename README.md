# TypeMaster

打字练习软件，包括基础打字练习、英语单词、Python编程等。用的技术栈为：React + TypeScript + Vite + Mantine + eslint。

## Task

- [x] 基础打字练习
- [x] 英语单词
- [x] Python编程
- [x] 作业帮
- [x] 显示键盘
- [ ] 自定义打字关卡，关卡打字内容可定制；
- [ ] 显示手势, 找一些指法图，覆盖到键盘上；
- [ ] 游戏模式
    - [ ] 萌宠PK 卡片搜集系统
        - 攻击防守捕获需要打的字都不一样；
        - 攻击：根据进度可发动不同等级的攻击力（普通攻击fj，强力攻击dfjk）
        - 防守：根据进度可增加不同等级的防御力
        - 捕获：根据进度可提升捕获器等级
        - 不同类别的打字任务（如字母、数字、单词、拼音、诗词等）搜集的萌宠不同
    - [ ] 机甲打落石
